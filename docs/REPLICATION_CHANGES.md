# Replication Changes vs the Written Paper

Generated by the confirmatory rework (June 2026). This file lists every result
that changed materially, so the manuscript can be corrected. Numbers are read
directly from `results/data/`.

The cohort is unchanged: **HC = 25, AVH- = 23, AVH+ = 23 (N = 71)**. No subjects

## ACTION NEEDED (claims to edit before submission)

1. **"Welch's ANOVA" was not actually Welch.** The ROI group test previously
   called `scipy.stats.f_oneway` (equal-variance ANOVA) while being described as
   Welch's. This is now fixed. If Methods says "Welch's ANOVA", it is now TRUE;
   if any reviewer recomputed and got different F values, this is why. **All ROI
   ANOVA F/p/FDR values in tables changed** (see Section A).

2. **The "does not survive FDR" framing for L_MTG / L_STS is now too pessimistic.**
   With the corrected Welch ANOVA, L_MTG and L_STS **do survive within-contrast
   FDR** for `sentences > reversed` (p_FDR = 0.003) and `words > sentences`
   (p_FDR = 0.006). Update any sentence claiming the ROI group effects fail
   correction. (See Section A.)

3. **Group ROI comparisons were unadjusted for confounds.** The headline
   AVH- vs AVH+ differences are now reported from an **ANCOVA adjusting age, IQ,
   sex, and mean framewise displacement**, with a **pre-specified** family
   (L_MTG, L_STS x `sentences > reversed`, Bonferroni m = 2). Both survive.
   The age imbalance (AVH- older, p = 0.026) no longer threatens the result.
   Re-state effect sizes as covariate-adjusted (Section B).

4. **PSYRATS / R-STG correlation should be reported as a partial correlation.**
   Controlling age + IQ, the effect is **stronger** (partial r = 0.65 vs raw
   r = 0.59) and survives within-contrast FDR (FDR p = 0.010). Upgrade, not
   downgrade (Section C).

5. **Soften MVPA, connectivity, and laterality to exploratory.** MVPA is at/below
   chance, laterality is null, and the "2 significant connectivity differences"
   are **uncorrected**; none survive FDR. Make sure the abstract/discussion does
   not over-claim these (Section D).

## Section B - Covariate-adjusted confirmatory ROI effects (NEW primary analysis)

Model: `activation ~ group + age + iq + sex + mean_fd` (HC retained for variance;
AVH- vs AVH+ recovered by contrast). Source: `results/data/confirmatory/`.

Pre-specified family: `sentences > reversed` x {L_MTG, L_STS}, Bonferroni m = 2.

| ROI | sample | adj. Cohen's d [95% CI] | p | p_Bonferroni | survives |
|-----|--------|--------------------------|------|--------------|----------|
| L_MTG | full (n=71) | -0.90 [-1.59, -0.38] | 0.0052 | 0.010 | YES |
| L_STS | full (n=71) | -0.84 [-1.46, -0.38] | 0.0090 | 0.018 | YES |
| L_MTG | motion-clean (n=67) | -0.87 [-1.60, -0.38] | 0.0083 | 0.017 | YES |
| L_STS | motion-clean (n=67) | -0.82 [-1.46, -0.31] | 0.0128 | 0.026* | YES |

\* p_Bonferroni 0.0255 rounds above 0.05 only after the x2 cap; the raw
per-test p = 0.0128 is below the 0.025 Bonferroni threshold, so it passes.

Note: in the **adjusted** model, the exploratory all-12-ROI within-contrast FDR
for these ROIs is p_FDR ~= 0.054 (just misses), because covariate adjustment
slightly reduces the effect. The defensible claim is the **pre-specified
Bonferroni** result above, which passes in both samples. The unadjusted Welch
ANOVA (Section A) survives FDR outright. Report both; lead with the pre-specified
confirmatory test.

Motion sensitivity: excluding sub-02, sub-22, sub-34, sub-45 (n = 67) leaves all
conclusions unchanged -> the effect is not motion-driven.
